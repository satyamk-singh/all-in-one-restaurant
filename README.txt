All in One Restaurant website
Owner: Satyam Singh | Near SBI Bank, Hussainabad, Palamu, Jharkhand 822116

FILES
index.html  - page structure (HTML)
style.css   - design (CSS)
script.js   - features: menu, cart, delivery, booking, 3D (JavaScript)
images/     - food photos

HOW TO RUN
Open index.html in a browser (internet needed for fonts and the 3D library).

SET YOUR NUMBER
Open script.js, find 91XXXXXXXXXX (first line) and replace it with the owner's number,
country code first, digits only (example 919876543210). Orders and bookings go to this WhatsApp.

CHANGE MENU / PRICES
In script.js, edit the list that starts with: var M=[

PUT ONLINE
Upload the whole folder to Netlify Drop, GitHub Pages or Cloudflare Pages.
